# Capability evaluation

## Capability and state

Record the skill/version or file state, host, inputs, intended scope, and
permitted effects. State whether this is structural inspection or a runtime trial.

## Cases

| Raw task/input | Trigger or non-trigger | Expected observable outcome | Actual evidence | Result |
|---|---|---|---|---|

Include a representative use, plausible non-trigger, and relevant failure
case. Compare a baseline when measuring the skill's effect is necessary.

## Decision

Record demonstrated value, friction, unsupported behavior, and the narrow
revision or next trial. Do not label a structural pass as validated judgment.
