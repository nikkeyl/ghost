# Personal authoring preferences

These preferences were supplied with the author's agent setup. They are an optional
profile, not a universal convention for every repository or team. Apply when the
adopting user enables this profile or requests the style; preserve explicit
repository requirements and the current user's scope.

- When a commit is requested, prefer one short Conventional Commit subject without a
  body or an AI-attribution trailer.
- Stage only the intended change. If a file contains other pending edits, select the
  relevant hunks and inspect the staged result.
- Keep PR drafts and review replies factual and natural; do not add an unsolicited
  AI-generation footer.

Enabling this profile does not authorize committing, staging, publishing, rewriting
history, or modifying another person's changes. Apply the Git and review rules for
those effects. Retain required attribution and source notices in documentation
independently of commit wording.
